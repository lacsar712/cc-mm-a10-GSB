# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报、可拉起/提交复测 |
| viewer | view123456 | 只能看（含复测任务与逾期栏） |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 复测任务

- 班测列表里的报警行可由检查员「拉起复测」，创建时填写截止时刻。
- 截止前在「复测任务 → 待复测」提交甲烷值，服务端生成新班测行（带「复测」标记），任务页把原报警编号与新行编号串成可点链接。
- 超过截止时刻未复测的任务自动进入「逾期栏」，逾期后不能再提交。
- 顶栏入口名为「复测任务」。旁观账号能看任务和逾期栏，但看不到拉起与提交按钮。

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 从回风巷报警行拉起复测任务，截止时刻选未来；在待复测里用 0.3 提交，任务进入已完成，在任务页点旧编号能跳到原报警行，点新编号能跳到新班测行。
5. 再拉一单，故意把截止时刻填到过去，任务不出现在待复测而是直接出现在逾期栏，且无法提交。
6. viewer 登录能打开「复测任务」看到待复测/逾期栏，但没有任何拉起或提交复测的按钮。
