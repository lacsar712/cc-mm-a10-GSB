# 矿井瓦斯班测台

检查员上报测点甲烷浓度。达到 1% 时，服务端通过网页套接字把这条报警推到已经打开的页面。页面是手写脚本，没有用组件框架，也没有图表。

报警行可以拉起一条复测任务，任务自带截止时刻。复测提交后生成新的班测行，任务页把原报警主键与新行串起来；逾期未复测的任务进逾期栏。顶栏入口叫“复测任务”。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3191 |
| 接口 | http://localhost:8191 |
| PostgreSQL | localhost:54391 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| gasman | gas123456 | 可上报 |
| viewer | view123456 | 只能看 |

## 启动

```bash
cd projects/12-mine-methane-shift
docker compose up --build
```

## 验收

1. 用 gasman 登录，列表里回风巷是报警，东翼-12 是正常。
2. 再开一个浏览器窗口同时看列表，上报一个大于等于 1 的测点，两个窗口都会出现新记录。
3. viewer 登录后没有上报表单。
4. 顶栏有“复测任务”入口。在回风巷报警行点“拉起复测”，选定截止时刻后生成任务，进入任务页的“待复测”栏。
5. 截止前在任务卡片上用 0.3 提交复测：生成一条新的班测行，任务进入“已完成”，卡片上可从“原报警 #旧编号”点到“新班测行 #新编号”（点击跳回列表并高亮），列表里新行也能回溯任务与原报警。
6. 再拉起一单，故意把截止时刻改到过去：任务立即出现在“逾期栏”，且不能再提交复测。
7. viewer 能打开复测任务页、看待复测/逾期/已完成三栏，但没有“拉起复测”和“提交复测”控件（接口直接调用返回 403）。
